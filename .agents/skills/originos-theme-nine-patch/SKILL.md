# OriginOS 7 短信卡片与卸载弹窗

先从目标主题读取实际资源、状态与尺寸。普通短信卡片和卸载弹窗可能共用设计语言，但需按各自的包路径和实机截图处理。

## 短信智能卡片

- 在 `com.android.mms` 中成对更新 `sms_card_view_bg.9.png` 和 `sms_card_view_bg_pressed.9.png`，保留按压反馈。亚津子版将全身 Q 版放在右下角，原羽毛位置还原为边框。角色的头、鞋和轮廓都应清晰。
- 按实机截图比例确定角色尺寸和正文区。返工版对比曾要求角色对角线至少增加三倍，验收应在渲染结果上测量。把纵向拉伸带留在角色上方，横向拉伸带放在避开装饰的平坦区域。用正文及按钮检查内容边距。

## 卸载底部弹窗

- 检查 `vivo/vigour_dialog_full_light.9.png` 与目标包实际存在的深色、OS2 和普通 PNG 变体。普通 PNG 用没有导线的内图。对目标弹窗修改时保留旧包的短信卡片和其他模块。
- 按参考把透明立绘放在弹窗顶部。亚津子试稿用约六成卡片宽度，头纱略探出上沿，底部自然淡入卡片。保留文案与确认、取消按钮的可读性。

## 点九图和验证

- 用 RGBA 源 `.9.png`。外框宽 1px，透明边上用不透明纯黑线标记，上、左为拉伸区，下、右为内容区。角像素透明，PNG 文件无二进制 `npTc`。保留角色所占的固定区。
- 用窄、宽及高卡片模拟，就地核对装饰比例、圆角、文字和按钮占位。打包时核对源 .itz、直用替换包内的相应条目与字节。分别记录模拟预览、已推到设备与实际应用后的观察。
