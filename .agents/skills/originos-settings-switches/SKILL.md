# OriginOS 设置头像开关

1. 找到用户确认的开启、关闭参考和目标主题的 `vivo` 开关资源。亚津子的设置开关使用单个 Q 版头像。先定关闭基准，再在同一底图上改开启态，保持头部的位置、比例、眼睛、发丝和透明区域一致。
2. 如果需求只改露齿笑，局部合成参考中的牙形，必要时轻微旋正和去除滤镜偏色。以目标尺寸保持嘴和牙的大小，在同一画布比较 RGBA，验收嘴部以外像素一致。
3. 透明源图等比缩入目标轨道。Studio 的 `make_switch_track_png()` 使用 `150×90` 画布，有效胶囊区约为 `x=12..138, y=12..78`。先检查目标开关的左右位置及原滑块是否挡脸，再确定头像位置。应用实际使用的 `vigour_bool_btn_bg_on_*`、`vigour_bool_btn_bg_off_*` 与 `vigour_switch_btn_*` 变体。项目将挡住头像的默认滑块或竖杠透明化，处理前先确认实际需要的状态。
4. 在目标 UI 大小比较两态、浅深色、按压和禁用状态。交接时清楚标明正式开关图的用途，正式资源目录只放当前选用的一对。把草稿放到工作区其他位置。
