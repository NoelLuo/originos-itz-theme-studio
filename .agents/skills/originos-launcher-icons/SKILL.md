# OriginOS 桌面应用图标

1. 先读取现有主题、映射 CSV 和批注。用实际包名定位应用及地区别名。新增手机应用时，可用 Studio 的 ADB 图标提取和缺失扫描获取参考。身份有疑问时，核对官方图标或有权使用的原图。
2. 优先提取可辨认的品牌主体，保留关键轮廓、色块位置与孔洞。以 `#98D7E1` 为亚津子主题的主色，可给围巾或其他完整配件换色。复杂品牌图标保留必要的原色，使用平面色块和沿主体闭合的细青金石色勾边。按批注控制线宽，品牌字形应保留特征。亚津子主题的设置光环沿用已确认的无勾边样式。
3. 复杂轮廓若有碎片、残底或抠图造成的锯齿，沿原标志重绘关键形状。游戏图标可先找有辨识度的道具或标志。按需求制作 Q 版时，参考用户提供或允许使用的正确角色图，核对发型、配件、神态和缩图后的表情。仅改表情时沿用现有构图与裁切。
4. 输出 `192×192` RGBA PNG，按 `icons/<package>.png` 打包。主体外用透明像素，内部依标志保留实白或真正挖空。只更新本次涉及的包名与确认的别名。保留现有映射和可回退的上一版，维护批注对应的全套总览。
5. 在浅底和深底以桌面显示尺寸看轮廓、孔洞、辨识度，再放大看残底、锯齿、歪斜和拉伸。复查 ZIP 的条目、PNG 尺寸和透明通道，并用 Studio 验证能导入。实机套用和工作台导入分别记录。
